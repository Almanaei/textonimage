# Quality Policy

## Purpose
Define minimum quality expectations across all outputs.

## Mandatory Quality Criteria
- outputs must be complete, scoped, and testable
- all critical assumptions must be explicit
- all APIs must define success and error behavior
- all rendering behavior must define overflow policy
- all user-facing flows must define error states

## Visual Quality Criteria
- name placement must remain inside the approved bounding box
- generated output must preserve template fidelity
- Arabic rendering must be legible and stable
- PNG must be high-resolution and usable on mobile devices
