# Standard Handoff Contract

## Purpose
This contract must be used whenever one agent passes work to another agent.

## Required Sections
### 1. Handoff Header
- from agent
- to agent
- date/time
- workflow state
- artifact version

### 2. Objective
What the receiving agent is expected to produce.

### 3. Approved Inputs
List of approved artifacts the receiver should trust.

### 4. Constraints
Non-negotiable constraints the receiver must preserve.

### 5. Required Decisions
Specific decisions the receiving agent must make.

### 6. Acceptance Criteria
Criteria that define success for the receiving artifact.

### 7. Known Risks
List of current risks or unresolved issues.

### 8. Escalation Conditions
Conditions under which the receiver must return the work instead of proceeding.
