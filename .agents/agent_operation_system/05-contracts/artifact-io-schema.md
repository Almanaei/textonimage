# Artifact IO Schema

## Required Metadata
- artifact_id
- artifact_name
- artifact_type
- version
- owner_agent
- status
- created_at
- upstream_artifacts

## Required Body Sections
- purpose
- scope
- decisions
- assumptions
- risks
- dependencies
- acceptance criteria
- open issues

## Status Values
- draft
- in_review
- approved
- rejected
- superseded
