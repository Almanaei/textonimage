# Review Scorecard

## Scoring Dimensions
Each reviewed artifact is scored from 1 to 5.

### 1. Clarity
Is the artifact understandable and unambiguous?

### 2. Completeness
Does it contain all required sections and decisions?

### 3. Consistency
Does it align with upstream artifacts and policies?

### 4. Testability
Can downstream teams validate it objectively?

### 5. Operability
Does it consider deployment, observability, and supportability where relevant?

## Pass Rule
- no dimension below 3
- average score at least 4 for gate-critical artifacts
