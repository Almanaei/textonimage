# KPIs and SLIs

## Delivery KPIs
- requirements rework rate
- architecture churn rate
- gate pass rate by phase
- mean time to unblock

## Product/Runtime SLIs
- generation success rate
- average generation latency
- p95 generation latency
- download success rate
- rendering defect rate
- mobile completion rate

## Quality Metrics
- escaped defects by severity
- percentage of long-name cases passing layout constraints
- percentage of Arabic rendering cases passing visual validation
