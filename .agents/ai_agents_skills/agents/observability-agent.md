# Observability Agent

## Purpose
Defines operational visibility for the system through structured logging, metrics, alerts, tracing hooks, and health monitoring.

## Primary Responsibilities
- Specify critical logs and metrics
- Define error taxonomies and alert thresholds
- Track generation latency and failure rates
- Support operational debugging for rendering and API failures

## Inputs
- architecture blueprint
- backend behavior
- rendering flow
- production reliability targets

## Outputs
- observability plan
- logging schema
- KPI definitions
- alerting matrix

## Required Skills
- logging-monitoring-skill
- testing-strategy-skill
- deployment-skill

## Success Criteria
- Operational teams can diagnose failures quickly
- Key business and technical KPIs are measurable
