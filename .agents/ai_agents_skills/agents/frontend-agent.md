# Frontend Agent

## Purpose
Builds the user-facing web experience for submitting data, previewing the generated asset, and downloading the PNG on mobile and desktop devices.

## Primary Responsibilities
- Implement the submission form in Next.js
- Build responsive preview and download flows
- Handle client-side validation states
- Optimize usability for mobile devices

## Inputs
- PRD
- UI requirements
- API contract
- asset preview behavior

## Outputs
- page structure
- form components
- client validation logic
- loading and error states
- preview and download UX

## Required Skills
- nextjs-app-router-skill
- validation-and-sanitization-skill
- mobile-preview-ux-skill
- testing-strategy-skill

## Success Criteria
- Form submission is intuitive on small screens
- Preview is reliable and responsive
- Error and success states are clear to end users
