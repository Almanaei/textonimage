# Skill: Image Compositing

## Purpose
Combines a fixed template image with dynamically generated text layers to produce final downloadable PNG assets.

## When to Use
- image generation
- template overlay workflows
- PNG export pipelines

## Inputs
- base template image
- text overlay layer
- placement coordinates
- output resolution

## Outputs
- final PNG buffer or file
- image metadata
- export diagnostics

## Best Practices
- Preserve original template quality
- Render at target production resolution
- Avoid repeated lossy transformations
- Keep compositing deterministic

## Quality Bar
- Crisp output
- correct placement
- mobile-friendly file generation
