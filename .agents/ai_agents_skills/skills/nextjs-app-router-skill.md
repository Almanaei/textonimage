# Skill: Next.js App Router Implementation

## Purpose
Implements application structure using Next.js App Router for modern server/client composition.

## When to Use
- page routing
- route handlers
- server components
- form workflows

## Inputs
- page map
- API needs
- data flow requirements

## Outputs
- folder structure
- route design
- component boundaries
- server/client separation strategy

## Best Practices
- Keep rendering-sensitive logic on the server
- Use Route Handlers for binary/file responses
- Use Server Actions selectively for form mutations when response shape permits
- Isolate UI state from core business logic

## Quality Bar
- Clear route boundaries
- minimal coupling
- deployable structure
