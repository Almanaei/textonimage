# Skill: Mobile Preview UX

## Purpose
Designs the form, preview, and download experience for mobile-first users who generate and save the PNG asset.

## When to Use
- mobile-first UI design
- preview flow design
- responsive optimization

## Inputs
- screen constraints
- user flow
- image preview behavior

## Outputs
- responsive layout guidance
- component behavior rules
- loading and success state recommendations

## Best Practices
- Keep the form short and focused
- Make primary actions thumb-friendly
- Show generation progress clearly
- Keep download action obvious after preview is ready

## Quality Bar
- low friction on mobile devices
- high completion rate
- readable preview and controls
