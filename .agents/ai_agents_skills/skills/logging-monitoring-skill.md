# Skill: Logging and Monitoring

## Purpose
Provides visibility into API behavior, rendering latency, failures, and production health.

## When to Use
- production readiness
- incident response preparation
- KPI instrumentation

## Inputs
- request lifecycle
- rendering pipeline
- operational goals

## Outputs
- log schema
- metric definitions
- alert conditions
- dashboard requirements

## Recommended Signals
- request count
- validation failure count
- generation success rate
- generation latency
- rendering failure count
- storage upload failure count

## Quality Bar
- actionable logs
- low-noise alerting
- meaningful service health visibility
