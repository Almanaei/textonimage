# Skill: API Route Design

## Purpose
Designs robust HTTP endpoints for request validation, business execution, and structured response handling.

## When to Use
- endpoint specification
- backend flow design
- external contract stabilization

## Inputs
- product behavior
- request payload shape
- error handling rules

## Outputs
- endpoint contract
- request/response schema
- error model
- status code map

## Best Practices
- Validate early
- Keep response envelopes consistent
- Separate validation errors from server failures
- Add idempotency considerations where useful

## Quality Bar
- Stable contract
- predictable error behavior
- easy frontend integration
