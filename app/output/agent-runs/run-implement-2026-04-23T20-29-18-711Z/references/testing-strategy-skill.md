# Skill: Testing Strategy

## Purpose
Defines the required test coverage for functional correctness, rendering quality, compatibility, and release readiness.

## When to Use
- before implementation freeze
- before release
- during regression planning

## Inputs
- PRD
- acceptance criteria
- architecture and component map

## Outputs
- test plan
- test matrix
- edge-case scenarios
- release criteria

## Coverage Areas
- unit tests
- API tests
- rendering correctness tests
- visual/regression checks
- mobile browser compatibility tests
- performance smoke tests

## Quality Bar
- Critical user flow is fully covered
- Rendering edge cases are not left to manual guesswork
