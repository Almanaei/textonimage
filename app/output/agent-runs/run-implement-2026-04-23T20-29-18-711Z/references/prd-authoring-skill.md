# Skill: PRD Authoring

## Purpose
Produces a professional Product Requirements Document that aligns stakeholders, product, engineering, and QA.

## When to Use
- MVP definition
- feature approval
- engineering handoff

## Inputs
- validated requirements
- business objectives
- user flows
- risks
- metrics

## Outputs
- PRD
- acceptance criteria
- assumptions and dependencies
- release phases

## Method
1. Define product summary and goals
2. Document user segments and primary journeys
3. Define requirements and constraints
4. Specify edge cases and risks
5. Translate goals into measurable success criteria

## Quality Bar
- Concise but complete
- Engineering-ready
- QA-testable
- Free of conflicting requirements
