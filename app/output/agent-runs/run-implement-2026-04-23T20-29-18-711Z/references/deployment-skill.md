# Skill: Deployment

## Purpose
Prepares the application for reliable release across staging and production environments.

## When to Use
- environment setup
- CI/CD design
- release planning

## Inputs
- architecture blueprint
- hosting target
- runtime dependencies
- secrets and config list

## Outputs
- deployment plan
- environment variable contract
- release checklist
- rollback plan

## Best Practices
- Keep environment configuration explicit
- Validate rendering library compatibility in the target runtime early
- Separate staging and production settings
- Define rollback steps before first release

## Quality Bar
- reproducible deployments
- runtime compatibility confirmed
- controlled release process
