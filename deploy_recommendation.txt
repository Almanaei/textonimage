Connect your GitHub repo (Almanaei/textonimage)
Point it at the app/ directory
Add a Postgres plugin — Railway wires up DATABASE_URL automatically
Set your env vars (STATS_SECRET, ADMIN_API_KEYS, etc.)
Deploy — Railway builds the Dockerfile and runs it
No server management, auto-deploys on every git push, and the docker-compose.yml you have is essentially the production blueprint already.
